# Android permissions needed

Since this project doesn't include the full `android/` folder (that gets
generated by `flutter create`), add these manually after you run
`flutter create .` in this folder (see SETUP.md).

## android/app/src/main/AndroidManifest.xml

Add these two lines INSIDE the `<manifest>` tag, ABOVE the `<application>` tag:

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

Without these:
- No `INTERNET` permission → every API call will silently fail (the app
  can't reach your Colab backend at all).
- No location permissions → the 📍 "use current location" button will
  throw a permission error every time.

## android/app/build.gradle

Make sure `minSdkVersion` is at least 21 (geolocator and flutter_map both
require this). Find this line and update it if it's lower:

```
minSdkVersion 21
```
